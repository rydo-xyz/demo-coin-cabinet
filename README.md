# Coin & Cabinet — DEMO ONLY

**Fictional UK arcade café** built for the **Kerbstone Studio** portfolio to demonstrate a premium Spark-tier hospitality / gaming venue website.

- Not a real venue
- Hours, location (DEMO · Manchester Northern Quarter — fictional), events, and menu are invented
- Do **not** present this as a live client
- Phone `01234 567894` is a placeholder

## Stack

Static HTML / CSS / JS. Google Fonts (Bungee + Nunito). Netlify Forms (`coin-cabinet-book`) with honeypot. Cream / cherry-red / teal retro arcade aesthetic.

## Deploy

Publish directory is `.` (this folder). No custom domain — `*.netlify.app` only. `X-Robots-Tag: noindex` via `netlify.toml`.

Netlify site name: `kerbstone-demo-coin-cabinet`
